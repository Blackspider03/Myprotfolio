# Rohan Satish Bhagwat — Personal Portfolio

A modern, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `style.css` — all styling and responsive layout
- `script.js` — navigation, scroll reveal and cursor effect
- `assets/rohan.jpg` — profile photo
- `assets/hero-bg.png` — AI/technology hero artwork

## Run locally
Just open `index.html` in a browser.

## Deploy
Upload the folder to GitHub and deploy it with Netlify, Vercel (static), GitHub Pages, or Render Static Site.

## Customize
Search in `index.html` for project names, descriptions, links, experience and contact information.
